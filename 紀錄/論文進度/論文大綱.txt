# MARI Quant System 專題研究論文報告

**題目**：基於解耦雙軌表徵與多智能體強化學習之量化交易系統：架構設計、實證診斷與證偽分析

**專題系統**：MARI (Multi-Agent Resilient Intelligence) Quantitative System

**程式代碼庫架構**：`data/`, `models/`, `agents/`, `utils/`, `scripts/`, `configs/`

---

## 摘要

本研究提出並實作一套適用於標普 500（S&P 500）大宇宙之高維量化交易系統——MARI（Multi-Agent Resilient Intelligence）Quant System。系統設計以工程紀律為核心，嚴格切分「六階段端到端生產管線（Phases 1–6）」與「平行診斷／消融實驗層（Diagnostic Layer）」。

研究進程中，系統克服了兩層技術瓶頸：

1. **底層工程缺陷排除**：透過合成標籤正向對照實驗（AUC 達 0.977–0.982），徹底修復了圖神經網路全域注意力稀釋 500 倍、風控門檻過寬及非對稱獎勵誘導等結構性錯誤。
2. **表徵資訊坍縮之問題重構**：藉由 24 項預測任務之全宇宙掃描（Workstream A），嚴格證偽了「28 維技術特徵在二元分類（漲／跌）框架下具預測力」之原假說（$H_{1a}$ 被拒絕）；進一步透過解耦之梯度提升決策樹（GBDT）實證，確認問題根源在於二元切分所造成的資訊損失，並證實「連續橫截面排序（Continuous Ranking）」可提煉出統計顯著之訊號（$H_{1b}$ 成立，5 種子樣本外 Rank IC = $+0.0232 \pm 0.0005$，$p = 0.0000$）。

在模組邊際貢獻消融中，實證表明空間圖專家（DyGAT）因過度平滑未帶來超額增益（OOS $\Delta\text{IC} = -0.0016$），而極端崩盤護欄雖成功阻絕 2020 年市場劇震（回撤由 SPY 之 $-33.72\%$ 降至 $-4.31\%$），卻衍生高達 $90.8\%$ 之現金部位癱瘓副作用。在最終生產回測中，貝氏尋優因防過擬合安全閥檢定給出 Deflated Sharpe Ratio (DSR) = 0.0000 而主動啟動熔斷，拒絕將過擬合參數發布至生產線。

此外，本研究深度稽核發現：美聯儲高收益債信用利差特徵（`BAMLH0A0HYM2`）存在長期資料缺失，干擾了風控模型之因果歸因；且目前生產管線所採納之 60 日預測週期在經長滯後 HAC 校正後顯著性消退，與診斷層取得之 5 日穩健訊號存在落差。本報告彙整全部架構、代碼職責、實驗矩陣與實證數據，並給出具體優化修訂路徑。

## 第一章 系統管線總體架構與工程設計

MARI Quant System 旨在結合深度時序網路、動態圖結構與強化學習，在大規模股票池中建立全自動化投資決策管線。本系統在工程架構上落實「生產運行」與「科研診斷」嚴格解耦的設計準則。

### 1.1 六階段生產管線（Production Pipeline）

生產路徑採單向推進架構，各階段職責明確，並將前一階段產物持久化為標準資料結構：

```
Phase 1: 資料與特徵工程 ───► Phase 2: 雙軌表徵預訓練 ───► Phase 3: GBDT 選股與護欄
  (DataFetcher /               (BuildDecoupledExtractors     (GBDTExpertAgent /
   FeatureEngineer /            + GraphSpatialFusionLayer)    LSBoost 排序 + Platt 校準)
   VQVAEAgent 降噪凍結)
         │                               │                             │
         ▼                               ▼                             ▼
Phase 4: 貝氏尋優 + DSR 熔斷 ──► Phase 5: 三軌 PPO 訓練 ───► Phase 6: Open-to-Open 前向回測
  (Run_BO_Hyperparameter_Tuning)  (Agent_PPO + CIO Awakening)   (Run_WalkForward_Backtest)

```

1. **Phase 1（資料與特徵工程）**：載入 Point-in-Time 股票池與宏觀指標，完成 28 維技術與宏觀特徵建構、GICS 產業橫截面中性化，並利用 VQ-VAE 實施高頻收益通道之降噪。


2. **Phase 2（雙軌表徵預訓練）**：訓練時序專家（Trans-LSTM）與空間圖專家（DyGAT），抽取低維時空市場表示向量（Embeddings）。


3. **Phase 3（機器學習選股與風控護欄）**：以 5-Fold Purged Cross-Validation 訓練 GBDT（LSBoost）以輸出連續排序值，並同步訓練分類模型（RUSBoost）搭配 Platt 機率校準以建立尾端極端暴跌護欄。


4. **Phase 4（超參數調優與安全熔斷）**：執行貝氏最佳化超參數尋優，強制綁定 Deflated Sharpe Ratio (DSR) 統計檢驗；若未達顯著標準則自動拒絕更新並觸發安全熔斷。


5. **Phase 5（多智能體強化學習調度）**：啟動三軌 PPO 智能代理人（Agent_PPO），學習於不同市場狀態下動態分配時序部位、空間部位與防禦性現金水位。


6. **Phase 6（滾動前向回測）**：以嚴格的 Open-to-Open 價格機制執行樣本外（OOS）滾動前向步進回測，結算真實交易摩擦下的績效指標。



### 1.2 平行診斷與消融實驗層（Diagnostic Layer）

為防止研發過程中的探索性腳本與數據挖掘偏差污染生產環境，MARI 建立獨立於生產主路徑的診斷體系：

* **Round 6–10**：針對底層張量流、梯度回傳、模型容量與特徵剪枝的工程完整性排查。


* **Workstream A**：脫離主模型之 24 項預測任務全宇宙橫截面掃描，用以確立特徵訊號的理論天花板。


* **Stage 2 / Stage 2.5（Task A, B, B'）**：連續目標重構、Newey-West 長滯後 HAC 頻寬校正與獨立 GBDT 交叉驗證。


* **P2-1 ~ P2-4**：核心組件（空間專家、崩盤護欄、PPO 集成、VQ-VAE 降噪）之單因子邊際貢獻消融實驗。



### 1.3 核心配置防護與防過擬合機制（`configs/Config.m`）

`configs/Config.m` 集中管理全域超參數，並透過封裝方法 `loadBOParams()` 建立了系統級的過擬合防火牆：

* 當讀取 `BO_Hyperparameters.mat` 時，系統強制比對內部記錄之 DSR 檢定值與 Robust Score。


* 若調優結果無法在統計上排除「多重試驗之數據挖掘假陽性」，系統強制終止載入並退回預設之學術中立基準（Benchmark Defaults）。


* 此設計落實了金融機器學習領域的防禦性工程原則，使量化管線具備「拒絕採用自身過擬合結果」的能力。

## 第二章 系統模組架構與程式功能實作解析

系統程式庫由 MATLAB 與 Python 共同建構（MATLAB 佔比 96.7%，Python 佔比 3.3%），嚴格遵守高內聚、低耦合原則。

### 2.1 資料處理層（`data/`）



* **`hybrid_crawler.py`**：爬取維基百科歷史修訂紀錄，重建 S&P 500 自 2006 年以來完整成分股異動（含已下市或剔除之標的），自底層消除存活偏差（Survivorship Bias）；串接 Yahoo Finance API 下載多維度 OHLCV 歷史行情，輸出無偏之 `master_universe.parquet`。


* **`fred_crawler.py`**：自動調取美聯儲 FRED 數據庫之宏觀序列（VIXCLS、T10Y2Y、BAMLH0A0HYM2、DGS10、UNRATE），並根據經濟報告實際公布日程強制設置發布延遲校正（`lag_days`），消除總經數據的前視偏差。


* **`DataFetcher.m`**：負責讀取大型 Parquet 檔案；以 SPY 之交易日為基準日曆對齊所有橫截面標的；運用 `parfor` 平行運算將長表轉換為多維時序寬矩陣，並設置報價合理性與流動性枯竭斷言檢驗。


* **`FeatureEngineer.m`**：建構 28 維特徵空間，涵蓋 3 維跨期相對動量特徵、15 維市場微觀結構與流動性特徵、10 維宏觀利率與信用利差特徵。對特徵執行 GICS 產業別橫截面 Z-Score 中性化：



$$\tilde{x}_{i,t} = \frac{x_{i,t} - \mu_{g,t}}{\sigma_{g,t}}, \quad \forall i \in \text{Industry } g$$



若該產業樣本數不足則回退至全市場中性化。此外，計算 60 日滾動視窗下之 Spearman 相對係數矩陣，並以 Engle-Granger 雙向協整檢定結合 Benjamini-Hochberg FDR 校正，輸出供圖神經網路使用之動態鄰接矩陣（Adjacency Matrix）。



### 2.2 模型特徵抽取層（`models/`）



* **`EMAQuantizer.m`**：向量量化（VQ-VAE）編碼簿模組。具備資料依賴（Data-dependent）初始化機制；前向推論採用歐氏距離最近鄰匹配，反向傳播利用直通估計器（Straight-Through Estimator, STE）；在訓練期間使用指數移動平均（EMA）更新碼字，並設置死向量喚醒邏輯（碼字使用率門檻 $< 0.5$ 時隨機重置），提供 `freeze()`/`unfreeze()` 介面防止推論期數據洩漏。


* **`BuildDecoupledExtractors.m`**：雙軌特徵抽取模型構建工廠。包含時序路徑（Trans-LSTM 或 Pure LSTM）與空間路徑（DyGAT），內建多種損失函數實作，如 Huber 損失、Soft-IC 損失與 Pairwise Ranking 損失：



$$\mathcal{L}_{\text{Soft-IC}} = - \frac{\sum_i (\hat{y}_i - \bar{\hat{y}})(y_i - \bar{y})}{\sqrt{\sum_i (\hat{y}_i - \bar{\hat{y}})^2 \sum_i (y_i - \bar{y})^2}}$$


* **`GraphSpatialFusionLayer.m`**：繼承自 `nnet.layer.Layer` 之自訂圖卷積融合層。支援輸入節點特徵矩陣與動態鄰接矩陣，實作 Kipf-Welling 對稱正規化拉普拉斯矩陣 $\tilde{D}^{-\frac{1}{2}}\tilde{A}\tilde{D}^{-\frac{1}{2}}$，並透過可學習標量 `MixLogit` 達成靜態產業拓撲與動態注意力的自適應凸組合。


* **`FeatureEvaluator.m`**：因子評價分析引擎。計算任意預測週期 $H$ 之橫截面 Spearman 資訊係數（IC）；在計算 Newey-West HAC-ICIR 時強制約束最大滯後階數 $\text{max\_lag} \ge H$，避免重疊收益虛增 t 統計量；內建特徵相關矩陣診斷，針對相關係數超過 0.85 之特徵對發出共線性警訊。



### 2.3 智能代理決策層（`agents/`）



* **`VQVAEAgent.m`**：封裝 VQ-VAE 降噪訓練流程。僅鎖定 1 日、5 日與 20 日相對收益通道（R1, R5, R20）進行降噪重建；嚴格限定於樣本內（IS）執行無監督重建訓練，推論期實施物理凍結，確保完全排除前視偏差。


* **`GBDTExpertAgent.m`**：核心機器學習決策模組。配置 5-Fold Purged Cross-Validation 流程，訓練 LSBoost 演算法進行橫截面預期收益連續排序；配置 RUSBoost 分類器預測下行尾端崩盤機率，並串接 Platt Scaling 進行機率校準；內建基於 K-means 背景樣本壓縮技術之 SHAP 特徵重要度歸因演算法。


* **`RawBaselineTrainer.m`**：純診斷用評估引擎。完全獨立於深度學習 Embeddings 之外，採用原始 28 維特徵直接訓練 GBDT 基準模型，提供二元分類 AUC 與連續迴歸 IC 雙模式輸出，作為診斷實證（Workstream A、Task B'）之基準對照。


* **`Agent_PPO.m`**：三軌連續動作空間 Actor-Critic 強化學習代理人。其動作向量為：



$$a_t = [\text{Softmax}(w_{\text{time}}, w_{\text{space}}), \text{Sigmoid}(w_{\text{cash}})]$$



損失函數採用 PPO Clipped Surrogate Objective 配合熵正則項（Entropy Bonus）。本模組鎖定 CPU 運行，旨在完整調用 Intel MKL 高並發多執行緒矩陣平行加速，避免小批次頻繁調度帶來的 GPU 傳輸瓶頸。



### 2.4 工具與檢驗庫（`utils/`）



* **`hac_significance_test.m`**：實作 Newey-West 異方差與自相關一致（HAC）共變異數矩陣估計，採用 Bartlett 核函數校正長週期收益之統計檢定。


* **`block_bootstrap_auc_by_day.m`**：日層級區塊自助抽樣（Day-level Block Bootstrap）檢驗器，在橫截面同日股票收益高度相關之條件下，評估 AUC 之 $95\%$ 信賴區間。


* **`block_bootstrap_ic_by_day.m`**：針對時序聚合之日 IC 序列實施 Case-resampling Bootstrap，專門用於長週期重疊收益檢驗。


* **`loss_functions.m`**：提供全域獨立之損失函數實作（註：與 `BuildDecoupledExtractors.m` 靜態損失重疊，已列入後續整理清單）。

## 第三章 核心問題演進與病因根因鏈

量化系統研發過程經歷了兩層不同維度的重大技術瓶頸，此遞進過程為本研究的核心診斷路徑。

### 3.1 第一層瓶頸：底層工程缺陷（已完全排除）

在初期開發（Phase 14.23）中，模型訓練損失完全卡滯於 $\ln(2) \approx 0.6931$。經逐層梯度檢查，確認為多項底層工程問題交疊所致：

1. **圖注意力稀釋錯誤**：`GraphSpatialFusionLayer` 在計算動態注意力權重時，採用 Dense Softmax 對全宇宙 504 檔成分股進行全域正規化。理論推導顯示，真實具備經濟關係的稀疏相鄰邊權重因此被稀釋約 500 倍，致使動態注意力機制實質退化為全域均勻池化。


2. **極端風控門檻偏誤**：下行暴跌護欄觸發門檻原設於分位數 $p50$，導致模型在正常市場波動下長期處於極端防禦狀態。


3. **PPO 獎勵不對稱**：非對稱獎勵函數誘導代理人尋找到持有全現金的退化解（Degenerate Policy）。



**驗證排除**：透過 Round 6 合成標籤實驗，在包含確定性訊號的數據上，時序專家與空間專家探針 AUC 分別達到 0.977–0.981 與 0.975–0.982，確認了梯度通道與張量形狀皆無阻塞，底層工程缺陷已獲得排除。

### 3.2 第二層瓶頸：表徵資訊坍縮與問題形式化錯誤（核心實證發現）

在修復工程缺陷後（Phase 15.5），實盤特徵的驗證損失依然無法突破 $\ln(2)$。深入監控顯示：

* 梯度範數正常回傳（$10^{-2} \sim 10^{-3}$ 量級）。
* 隱空間表徵變異數（Embedding Variance, $E\_Var$）保持健康，未發生單點塌縮。
* 然而下游線性探針與決策樹之預測 AUC 恆常徘徊於 0.50 附近。



此現象證實：特徵提取器並非遭遇優化死鎖，而是在當前特徵與標籤形式下無法提取具備超額預測力的 Alpha 訊號。 28 維常用技術指標在「二元分類（漲 vs. 跌）」的任務形式化下，訊噪比（Signal-to-Noise Ratio）趨近於零，從而引發了後續的「訊號存在性全面檢定」。

### 3.3 端到端生產實測績效與 DSR 統計熔斷

在完成上述架構修復後，端到端生產管線之實際回測表現如下表所示：

| 評估維度 | MARI 系統表現 | SPY 基準指標（Benchmark） | 差異分析與統計判定 |
| --- | --- | --- | --- |
| **樣本內總報酬 (IS: 2006–2021)**<br> | $+29.03\% \sim +50.38\%$<br> | $+414.47\%$<br> | 策略嚴重落後大盤基準

 |
| **樣本內夏普比率 (IS)**<br> | $0.19 \sim 0.29$<br> | $0.64$<br> | 風險調整後收益顯著偏低

 |
| **樣本外總報酬 (OOS: 2022–至今)**<br> | $-3.14\% \sim -18.16\%$<br> | $+68.99\% \sim +71.35\%$<br> | 策略在樣本外呈現負報酬

 |
| **樣本外夏普比率 (OOS)**<br> | $-0.03 \sim -0.22$<br> | $0.73 \sim 0.75$<br> | 策略於升息週期嚴重受挫

 |

在 Phase 4 執行 26 次貝氏尋優迭代後，系統根據 Marcos López de Prado 理論計算其夏普比率之過擬合機率懲罰：


$$\text{DSR} = \Phi\left( \frac{(\text{SR} - \text{SR}^*) \sqrt{T-1}}{\sqrt{1 - \gamma_3 \text{SR} + \frac{\gamma_4 - 1}{4}\text{SR}^2}} \right)$$


實測計算得出 **$\text{DSR} = 0.0000$**。此結果確認：在經由多重試驗次數（$N=26$）、回測長度與收益偏態峰態校正後，該最佳化參數之表現無法在統計上排除隨機性。系統防禦安全閥隨即啟動熔斷，拒絕採用調優參數，強制退回學術中立配置。

## 第四章 診斷實驗設計、消融矩陣與實證檢定

## 第五章 關鍵資料缺失稽核與架構落差探討

經由對底層數據庫 `data/data_lake/` 與主排程代碼進行深度交叉比對，本報告揭露兩項直接影響論文防禦力之關鍵缺口。

### 5.1 FRED 信用利差特徵長期缺失（資料完整性與因果歸因偏差）

對宏觀資料庫 `data/data_lake/fred_macro.csv` 進行逐行稽核，發現異常現象：

* **數值缺失**：**美聯儲高收益債信用利差指標（`BAMLH0A0HYM2`）自 1990 年起至 2023 年 8 月 29 日全數為空值（NaN）**，僅在 2023 年 8 月 30 日之後方出現真實報價（而美聯儲 FRED 官方實際自 1996 年即提供每日連續數據）。
* **機制連鎖影響**：
1. 特徵處理代碼 `FeatureEngineer.m` 對缺失值採用 `fillmissing('previous')` 配合 `fillna(0)` 處理。這意味著在系統長達 15 年的樣本內訓練期（IS: 2006–2021）以及絕大部分樣本外期間，此項被文獻視為核心領先指標之特徵，實質上退化為全域常數 0。


2. 此發現直接挑戰了論文草稿 5.1 節關於崩盤護欄的歸因解釋。原稿觀察到「RUSBoost 崩盤護欄之 OOF AUC 隨 Fold 推進顯著遞增（Fold 1: 0.507 $\to$ Fold 2: 0.502 $\to$ Fold 3: 0.589 $\to$ **Fold 5: 0.775**）」，並將其歸因為「後期資料集納入更多真實市場危機樣本」。然而，Fold 5（涵蓋 2023 年後）在時序上恰好與 `BAMLH0A0HYM2` 數據重新上線完全重疊。




* **對策建議**：這兩種解釋目前在經驗上並存。需對該特徵實施零置換消融檢驗（Ablation Check），以驗證 Fold 5 AUC 躍升究竟係模型泛化提升，抑或單純為該指標補齊所帶來的結構性突躍。

### 5.2 生產管線目標週期（60D）與獨立診斷最優訊號（5D）之實證落差

審查 `Run_Extractor_Pretrain.m`（Phase 2 生產腳本）代碼，其訓練目標已切換為「60 日連續 Z-Score（Direction 2）」。然而對比診斷層之統計證據，存在明顯矛盾：

1. **Stage 2.5 Task A**：60D 訊號優於短期基準之假說，在正確引入滯後階數 $\text{max\_lag} = 60$ 之 Newey-West HAC 頻寬校正後，$p$ 值由 0.044 上升至 0.342，失去了統計顯著性。


2. **P2-1 生產規模消融**：60D IC 雖在樣本內達 $+0.047$，但在全市場樣本外（OOS）急跌至 $+0.019$ ($p = 0.19$)，未達可部署門檻（NO-GO）。


3. **Stage 2.5 Task B' 獨立基準**：在排除深度學習黑盒子之獨立 GBDT 測試中，全宇宙最穩定、五種子全數顯著之預測目標實為 **5 日週期訊號（5D）**，其樣本外 Rank IC 達到 $+0.0232 \pm 0.0005$ ($p = 0.0000$)。



目前生產系統尚未針對「5D vs. 60D 進行端到端全管線回測對照」，直接鎖定 60D 作為生產目標缺乏一致的實驗依據。將訓練目標調整為 5D 具備較高的成功機率與修復投資報酬率。

## 第六章 系統嚴謹性、實用性與可解釋性優化提案

為完備本專題在論文答辯與成果發表之學術品質，提出以下具體實施步驟：

### 6.1 核心實證修補（優先度：高）

1. **5D vs. 60D 端到端生產對照實驗**：
* 調整 `Run_Extractor_Pretrain.m` 至 `Run_WalkForward_Backtest.m` 之目標週期參數，完整運行 5D 目標之端到端測試，產出橫截面 Rank IC、策略夏普值、最大回撤與換手率對比表，消弭診斷與生產的不一致。




2. **`BAMLH0A0HYM2` 數據重新抓取與護欄特徵消融**：
* 修正 `fred_crawler.py` 之抓取請求邏輯，重構自 1996 年以來之完整歷史利差資料；將該特徵置零重跑 RUSBoost 崩盤模型，評估其對 Fold 5 AUC 之實質影響，並於論文附錄增列「資料品質稽核（Data Integrity Audit）」專節。





### 6.2 交易實用性與風控調優（優先度：中）

3. **崩盤護欄「防禦力 vs. 市場參與度」權衡曲線掃描**：
* 針對 P2-2 曝露之「$90.8\%$ 現金癱瘓」問題，對風控觸發閾值 $\tau_{\text{noise}}$ 進行百分位掃描（$p70, p75, p80, p85, p90$），量化系統「下行保護程度」與「上行捕捉率（Up-capture Ratio）」之非線性邊界，將風控模組提升為多目標權衡分析。




4. **交易摩擦成本雙向敏感度壓力測試**：
* 基於論文論點（微弱 IC 經轉化後之基礎超額收益難以抵消實體衝擊），在目前固定的手續費（BaseFrictionFee = $0.05\%$）與滑價係數（SlippageVolCoeff = $0.10$）基礎上，增設 $\pm 50\%$ 之成本敏感度矩陣，嚴格界定策略轉化為實盤之盈虧平衡點。



### 6.3 計量嚴謹度與可解釋性深化（優先度：中）

5. **組合對稱淨化交叉驗證（CPCV）與過擬合機率（PBO）**：
* 導入 Marcos López de Prado（2018）提出的 Combinatorial Purged Cross-Validation 演算法，針對 Phase 6 參數空間計算回測過擬合機率（Probability of Backtest Overfitting, PBO），提供較傳統單一 IS/OOS 切分更強的計量防禦力。


6. **全實驗族系誤差率（FWER / FDR）校正彙總**：
* 將 Round 6–10、P2-1–P2-4 及 Stage 2/2.5 之檢定 $p$ 值，統一於附錄編製 Benjamini-Hochberg FDR 與 Bonferroni 校正對照表，展現統計學上之一致性防禦標準。


7. **PPO 強化學習代理人之正向對照組建置**：
* 比照 Round 6 之設計哲學，建立具備線性確定性收益之合成環境，驗證 `Agent_PPO.m` 演算法本體是否具備策略收斂能力，釐清實盤不收斂究竟源自「演算法實現缺陷」或「金融狀態空間缺乏馬可夫性」。




8. **軟硬體環境陳述之精確化修訂**：
* 於論文研究限制專節中精確釐清運算架構：Phase 2 深度特徵抽取具備 NVIDIA RTX 4060 GPU 加速；而 `Agent_PPO` 係為充分利用 Intel MKL 之多核心矩陣並行能力以提升小批次抽樣吞吐量，刻意鎖定 CPU 運行，避免論文敘述與實際日誌產生矛盾。

## 第七章 結論

MARI Quant System 的研究價值不僅體現於建構一套整合多智能體與圖神經網路之高維量化系統，更在於其採用批判性實證方法，逐步釐清複雜金融架構的邊界條件。

本研究證實：

1. **形式化定義重於架構複雜度**：高維技術特徵在二元分類框架下無法學得有效資訊，盲目堆疊自注意力或圖卷積僅能減緩過擬合發散，無法無中生有創造 Alpha；轉向橫截面連續排序方為提取弱訊號之有效路徑。


2. **防禦性工程機制的實質價值**：內建的 DSR 安全閥能夠有效抵禦數據挖掘陷阱，在策略未達統計顯著時主動啟動熔斷，防止病態模型流入生產環境。


3. **極端風控之代價權衡**：防禦尾端崩盤與維持資本利用率存在本質上的拉鋸，風控設計必須自單點觸發邁向連續動態權衡。



本報告完整彙整了系統各模組代碼功能、兩層問題演進、實證數據矩陣與潛在數據漏洞。在後續推動 5D 目標端到端驗證與 FRED 信用利差資料修復後，本專題將具備完整的學術防禦性與工程實用價值。
